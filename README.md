# Explainable SAR Drafting Assistant

BITS Pilani WILP final-semester project proposal. Generates evidence-grounded, human-reviewed narrative drafts from synthetic case records.

**Planning stage only. No application has been implemented.**

- [Full project plan](docs/PROJECT_PLAN.md)
- [Decisions and assumptions](docs/DECISIONS.md)
- [Git workflow](docs/GIT_WORKFLOW.md)

Core scope: source-traceable claims, deterministic transaction timeline and totals, missing-information detection, structured RAG generation, reviewer editing, and controlled evaluation against baselines.

All outputs remain drafts. The project does not file reports or determine that a crime occurred. Use synthetic data only.
